# Swift Ship Tracker — Establish Relationships Between Objects

**Implementation guide · Step 02 of 10**

## Objective

Open Object Manager → Parcel → Fields & Relationships → New. Create relationship fields from Parcel to Sender and Parcel to Receiver. Open Delivery and create a relationship field to Parcel. Add an Assigned Agent relationship to a Salesforce User or Agent custom object. Choose Lookup or Master-Detail based on ownership, sharing and deletion requirements. Create sample records and verify the links.

## Expected result

Each parcel is linked to its sender and receiver, and each delivery record is linked to its parcel.
