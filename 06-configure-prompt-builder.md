# Swift Ship Tracker — Configure Prompt Builder

**Implementation guide · Step 06 of 10**

## Objective

Open Setup and search for Prompt Builder; confirm it is available in your org. Create a prompt template for a parcel task, such as explaining the latest delivery status. Instruct the AI to use only supplied Salesforce data and never invent tracking details or delivery dates. Add the appropriate record context, preview and test with valid, missing and ambiguous data, then save and activate the template.

## Expected result

The prompt produces clear, grounded answers and handles unavailable information honestly.
