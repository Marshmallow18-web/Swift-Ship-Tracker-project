# Swift Ship Tracker — Build Delivery Assignment and Status Update Flows

**Implementation guide · Step 05 of 10**

## Objective

Create a Screen Flow for admin assignment or a record-triggered flow for automation. Record the assigned agent on the Delivery record. Define statuses: Booked, Picked Up, In Transit, Out for Delivery, Delivered and Failed Delivery Attempt. Create a controlled agent screen or record page for status updates and notes. Where appropriate, update the Parcel status when its Delivery record changes. Test assignment and each status transition.

## Expected result

Admins can assign deliveries and agents can update progress while the parcel shows its latest status.
