# Swift Ship Tracker — Create Salesforce Objects and Fields

**Implementation guide · Step 01 of 10**

## Objective

Create four custom objects in Salesforce: `Sender__c`, `Receiver__c`, `Parcel__c` and `Delivery__c`. Open Setup → Object Manager → Create → Custom Object. Add suitable fields: sender/receiver name, phone, email and address; parcel tracking number, type, weight, booking date and status; delivery agent, status, attempt date, delivered date and notes. Save each object and field.

## Expected result

Four custom objects exist with the basic fields required by the project.
