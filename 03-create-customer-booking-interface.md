# Swift Ship Tracker — Create the Customer Booking Interface

**Implementation guide · Step 03 of 10**

## Objective

Choose a Salesforce Screen Flow, Experience Cloud page or another supported customer-facing interface. For a Screen Flow, open Setup → Flows → New Flow → Screen Flow. Add fields for sender, receiver, pickup and delivery addresses, parcel type and weight. Mark required fields, add a review/confirmation screen, then save, activate and test. Configure authentication and external-user permissions before exposing a portal publicly.

## Expected result

A user can enter the required parcel details and proceed to a booking confirmation.
