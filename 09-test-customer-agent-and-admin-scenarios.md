# Swift Ship Tracker — Test Customer, Delivery Agent and Admin Scenarios

**Implementation guide · Step 09 of 10**

## Objective

Customer tests: create a booking, receive a tracking number, track a parcel and view permitted delivery information. Agent tests: view assigned deliveries and update status or notes. Admin tests: review records, assign agents and monitor progress. Also test invalid tracking numbers, missing fields, invalid values, unauthorized actions and notifications. Record defects, fix them and repeat affected tests.

## Expected result

The main workflows pass for all three roles, with suitable validation, permissions and error handling.
