# Swift Ship Tracker — Connect Agentforce to Salesforce Actions and Flows

**Implementation guide · Step 08 of 10**

## Objective

Identify the flows/actions needed, such as Find Parcel by Tracking Number, Create Parcel Booking and Submit Delivery Change Request. Confirm each flow has clear input/output variables and safe error handling. Expose supported flows as Agentforce actions, add them to relevant topics and describe when they should be used. Set permissions and require customer verification before revealing private details or changing a delivery. Test invalid IDs, missing inputs and unauthorized requests.

## Expected result

The agent invokes the correct Salesforce action and reports the actual result.
