# Swift Ship Tracker — Create the Agentforce AI Agent

**Implementation guide · Step 07 of 10**

## Objective

Open Agentforce or Agents in Salesforce Setup, depending on your org interface. Create a new agent using an available agent type and channel. Name it Swift Ship Assistant. Write instructions explaining that it helps with parcel booking, tracking and delivery questions. Create topics or capabilities for supported tasks. Tell it to request a tracking number when needed, protect customer information and hand off unsupported requests. Save and test it in preview.

## Expected result

The agent understands supported parcel-related requests and responds within its configured scope.
